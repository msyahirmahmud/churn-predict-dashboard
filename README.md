> Machine Learning Customer Churn Analytics Predictor model with feature weight classification and risk threshold scoring.

---

## 🌟 Features

- **🤖 Sigmoid Activation Model**: Logistic regression churn probability calculation.
- **🎯 Feature Importance**: Weights tenure, monthly charges, support tickets, and billing settings.
- **🚦 Risk Categorization**: Classifies user cohorts into LOW, MEDIUM, or HIGH risk categories.

---

## 🚀 Quick Start

```bash
git clone https://github.com/msyahirmahmud/churn-predict-dashboard.git
cd churn-predict-dashboard
python3 main.py
```

Run test suite:
```bash
python3 -m unittest discover tests
```
